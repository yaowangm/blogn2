# 数据库表ID字段修复脚本

## 概述

`fix_table_ids.py` 是一个用于修复PostgreSQL数据库中所有表的id字段的脚本，将其转换为自增长格式和主键。

## 功能

- 自动检测数据库中所有表
- 检查每个表的id字段状态
- 将id字段修复为BIGSERIAL PRIMARY KEY格式
- 创建必要的序列和约束
- 保持现有数据的完整性

## 使用方法

```bash
# 在项目根目录执行
python3 scripts/fix_table_ids.py

# 或者直接执行（需要执行权限）
./scripts/fix_table_ids.py
```

## 修复过程

脚本会执行以下步骤：

1. **删除现有主键约束**（如果存在）
2. **删除默认值**（如果存在）
3. **修改字段类型为BIGINT**
4. **设置NOT NULL约束**
5. **创建自增序列**
6. **设置序列起始值**（基于现有数据）
7. **设置默认值为序列**
8. **设置序列所有者**
9. **添加主键约束**

## 注意事项

⚠️ **重要警告**：
- 此脚本会修改数据库结构
- 请在执行前备份数据库
- 确保有足够的权限执行DDL操作
- 建议在维护窗口期间执行

## 适用场景

- 解决 "Instance has a NULL identity key" 错误
- 将现有表的id字段转换为自增主键
- 数据库结构标准化

## 依赖

- Python 3.7+
- SQLAlchemy
- SQLModel
- PostgreSQL数据库

## 错误处理

脚本包含完整的错误处理机制：
- 网络连接错误
- 权限不足
- 表结构异常
- 用户中断操作
