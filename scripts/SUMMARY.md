# 存量数据向量化脚本总结

## 📁 文件结构

```
scripts/
├── batch_vectorization.py      # 多进程版本（推荐大数据量）
├── simple_vectorization.py     # 简化版本（推荐小数据量）
├── test_vectorization.py       # 测试脚本
├── example_usage.sh           # 使用示例
├── README.md                  # 详细说明文档
├── FIXES.md                   # 问题修复说明
└── SUMMARY.md                 # 本总结文档
```

## 🚀 快速开始

### 1. 测试环境
```bash
python scripts/test_vectorization.py
```

### 2. 基本使用（推荐）
```bash
# 清空向量表并重新开始
python scripts/simple_vectorization.py --clear-tables

# 从中断点恢复
python scripts/simple_vectorization.py --resume
```

### 3. 大数据量（多进程）
```bash
# 8个进程并行处理
python scripts/batch_vectorization.py --processes 8 --clear-tables
```

## ✨ 核心功能

### 1. 多进程支持
- **batch_vectorization.py**: 支持多进程并行处理
- **simple_vectorization.py**: 单进程顺序处理
- 默认进程数：4个
- 可通过 `--processes N` 指定

### 2. 中断恢复
- 自动检测已处理的记录
- 文章：检查 `article_vectors.projectitem_id` 最大值
- 评论：检查 `comment_vectors.post_id` 最大值
- 使用 `--resume` 参数恢复

### 3. 进度显示
- 每10条记录显示进度
- 显示完成数量/总数量/百分比
- 显示当前处理ID和用时
- 生成详细日志文件

### 4. 数据清理
- `--clear-tables`: 清空所有向量表
- 支持选择性处理：`--articles-only` / `--comments-only`

## 📊 性能对比

| 版本 | 适用场景 | 内存使用 | 处理速度 | 复杂度 |
|------|----------|----------|----------|--------|
| 简化版 | 小数据量(<1000条) | 低 | 慢 | 简单 |
| 多进程版 | 大数据量(>1000条) | 高 | 快 | 复杂 |

## 🔧 技术实现

### 1. 向量化流程
```
数据源 → 向量化服务 → 向量表存储
```

### 2. 数据表结构
- **源表**: `projectitem` (文章), `post` (评论)
- **向量表**: `article_vectors`, `comment_vectors`, `content_segment_vectors`

### 3. 恢复机制
- 检查向量表中的最大ID
- 从最大ID+1开始处理
- 支持部分完成的数据

## 📝 使用建议

### 1. 首次使用
1. 运行测试脚本验证环境
2. 使用简化版本处理少量数据
3. 确认结果正确后使用多进程版本

### 2. 生产环境
1. 使用多进程版本提高效率
2. 设置合适的进程数量（CPU核心数的1-2倍）
3. 监控内存使用情况

### 3. 故障处理
1. 中断后使用 `--resume` 恢复
2. 查看日志文件定位问题
3. 必要时清空向量表重新开始

## 🚨 注意事项

1. **首次运行**: 会下载BERT模型，需要网络连接
2. **内存使用**: 多进程版本会占用更多内存
3. **中断恢复**: 建议使用 `--resume` 参数
4. **数据备份**: 重要数据建议先备份
5. **监控日志**: 关注日志文件中的错误信息

## 📞 故障排除

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 数据库连接失败 | 配置错误 | 检查数据库配置 |
| 模型加载失败 | 网络问题 | 检查网络连接 |
| 内存不足 | 进程数过多 | 减少进程数量 |
| 权限错误 | 权限不足 | 检查数据库权限 |
| 中断后无法恢复 | 数据不一致 | 清空向量表重新开始 |
